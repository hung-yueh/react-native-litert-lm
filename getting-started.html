Getting started

Install the library, load a Gemma model, and stream your first tokens — entirely on the device.

Requirements

DependencyVersion
React Native0.76+
react-native-nitro-modules0.36.0+
LiteRT-LM engine (bundled)0.15.0
AndroidAPI 26+, arm64-v8a
iOS15.1+, arm64
ARM only

Only ARM devices and simulators are supported. x86_64 Android emulators will not run the engine.

Install

shell
npm install react-native-litert-lm react-native-nitro-modules

Expo

Add the config plugin, then prebuild:

app.json
{
  "expo": {
    "plugins": ["react-native-litert-lm"],
    "android": { "minSdkVersion": 26 }
  }
}
shell
npx expo prebuild
npx expo run:ios      # or run:android

Bare React Native

shell
# iOS
cd ios && pod install

# Android
cd android && ./gradlew clean

iOS entitlement for large models

Models over ~2 GB need Extended Virtual Addressing, or iOS caps virtual memory at ~2 GB and Jetsam kills the app during load. This applies to all three bundled model constants (GEMMA_4_E2B_IT, GEMMA_4_E4B_IT, GEMMA_3N_E2B_IT_INT4).

App.entitlements
<key>com.apple.developer.kernel.extended-virtual-addressing</key>
<true/>
Note

The entitlement requires a paid Apple Developer account.

First inference

useModel owns the whole lifecycle: it downloads the model with progress, runs a pre-flight memory check, loads the engine, and cleans up on unmount.

Chat.tsx
import { useModel, GEMMA_4_E2B_IT } from "react-native-litert-lm";

function Chat() {
  const { model, isReady, downloadProgress, error } = useModel(
    GEMMA_4_E2B_IT,
    {
      backend: "cpu",
      systemPrompt: "You are a helpful assistant.",
      enableMemoryTracking: true,
    },
  );

  if (error) return <Text>{error}</Text>;
  if (!isReady)
    return <Text>Loading… {Math.round(downloadProgress * 100)}%</Text>;

  const ask = async () =>
    console.log(await model.sendMessage("Hello!"));

  return <Button title="Generate" onPress={ask} />;
}

Stream tokens

For a chat UI, stream with execute() — or get typed token / toolCall / thinking events from executeWithEvents().

typescript
await model.execute(
  [{ type: "text", text: "Write a haiku about RAM." }],
  (token, done) => {
    if (!done) appendToUI(token);
  },
);

Outside React

createLLM() gives you the same engine imperatively — for background tasks, services, or your own state management.

typescript
import { createLLM } from "react-native-litert-lm";

const llm = createLLM();
await llm.loadModel("https://example.com/model.litertlm", { backend: "gpu" });
const reply = await llm.sendMessage("What is the capital of France?");
llm.unload(); // free the engine; llm stays reusable
