Core API

useModel

One hook that owns the whole model lifecycle: download with progress, pre-flight memory check, load, inference, and cleanup on unmount — with memory state exposed reactively.

Signature

function useModel( pathOrUrl: string, config?: UseModelConfig, ): UseModelResult

pathOrUrl is a local file path or an HTTPS URL. When it is a URL, the hook downloads the model to the native cache (reporting downloadProgress), runs the automatic pre-flight memory estimate, loads the engine, and closes the underlying instance when the component unmounts. Use it when a component's lifetime should own the model; for background tasks or your own state management, use createLLM directly.

Usage

Chat.tsx
import { useModel, GEMMA_4_E2B_IT } from "react-native-litert-lm";

function Chat() {
  const {
    model,
    isReady,
    isGenerating,
    downloadProgress,
    error,
    generate,
    reset,
    deleteModel,
  } = useModel(GEMMA_4_E2B_IT, {
    backend: "cpu",
    systemPrompt: "You are a helpful assistant.",
    enableMemoryTracking: true,
  });

  if (error) return <Text>{error}</Text>;
  if (!isReady)
    return <Text>Loading… {Math.round(downloadProgress * 100)}%</Text>;

  const ask = async () => {
    const reply = await generate("Hello!"); // or model.execute(...) for streaming
    console.log(reply);
  };

  return (
    <>
      <Button title="Generate" onPress={ask} disabled={isGenerating} />
      <Button title="New chat" onPress={reset} />
      <Button title="Free storage" onPress={() => deleteModel()} />
    </>
  );
}

model is a full LiteRTLMInstance, so everything on the inference API — streaming execute(), typed executeWithEvents(), conversations — is available once isReady is true.

UseModelConfig

Extends LLMConfig — every engine config field (backend, maxContextTokens, systemPrompt, tools, thinking, …) is forwarded to the native load. See Configuration for the full list. The hook adds three fields of its own:

FieldTypeDefaultMeaning
autoLoad boolean true Download and load the model on mount. Set false to defer until you call load().
enableMemoryTracking boolean false Track memory usage after each inference call, storing snapshots in a native ArrayBuffer (zero-copy). Enables memoryTracker and memorySummary.
maxMemorySnapshots number 256 Maximum snapshots retained (ring buffer). Each snapshot uses 32 bytes of native memory.
Note

A config-parity contract test enforces that every LLMConfig key is forwarded to the native load or explicitly excluded — new config fields cannot silently go missing from the hook.

UseModelResult

FieldTypeMeaning
model LiteRTLMInstance | null The underlying instance — full inference and memory API. null until created.
isReady boolean True once the model is loaded and ready for inference.
isGenerating boolean True while a generate() call is in flight.
downloadProgress number Download progress as a 0–1 fraction (render as Math.round(downloadProgress * 100)%).
error string | null Last load or generation error message, or null.
generate (prompt: string) => Promise<string> Run a text prompt and resolve with the full response. Throws if the model is not ready.
reset () => void Clear the conversation context (calls model.resetConversation()).
deleteModel (fileName?: string) => Promise<void> Delete the model file from the cache. If no fileName is provided, derives it from the URL/path passed to useModel.
load () => Promise<void> Download (if needed) and load the model manually — for autoLoad: false or retrying after an error.
memoryTracker MemoryTracker | null Snapshot tracker backed by a native ArrayBuffer. Available when enableMemoryTracking is true.
memorySummary MemoryTrackerSummary | null Current tracking summary (peak/average/current RSS, native heap). null if tracking is disabled; updates automatically after each inference call.
memoryEstimate MemoryEstimate | null Pre-flight memory estimate for the loaded model (null until loaded). Refreshed after each load.
memoryForecast MemoryForecast | null Context-window / KV-cache growth forecast for the active conversation. Refreshed after each generate() call — watch nearingLimit to warn users before the context (and its memory) runs out.
memoryWarning MemoryWarningLevel | null Last OS memory-pressure warning ('moderate' or 'critical') received while the hook was mounted, or null. Reset on each successful load.

The memory types (MemoryEstimate, MemoryForecast, MemoryTrackerSummary, MemoryWarningLevel) are documented on Memory & errors.

Behavior notes

  • Auto-load on mount, close on unmount. The hook creates the instance via createLLM({ enableMemoryTracking, maxMemorySnapshots }), loads on mount when autoLoad is true, and closes the instance when the component unmounts — no manual cleanup needed.
  • Inline config objects are safe. The config is destructured into primitives for stable dependency arrays (tools and thinking are tracked via JSON.stringify keys), so passing a fresh object literal on every render does not cause reload loops.
  • generate() before ready throws. Calling it while isReady is false throws Error("Model not ready"). On failure it sets error and rethrows.
  • deleteModel() derives the filename from the URL when called without an argument, deletes through ModelRegistry.deleteFile, and resets isReady and downloadProgress.
  • After each successful load, memoryWarning is reset, memoryEstimate and memoryForecast are refreshed, and the hook subscribes to OS memory-pressure warnings via setMemoryWarningCallback (silently skipped on older native builds).
  • After each generate(), memorySummary and memoryForecast are refreshed — watch memoryForecast.nearingLimit.

Memory state, reactively

Because the forecast is refreshed after every generate() and the warning is fed by OS pressure signals, plain conditional rendering is enough to warn users at the right moment:

typescript
const { generate, memoryForecast, memoryWarning } = useModel(GEMMA_4_E2B_IT);

// After each generate(), memoryForecast is up to date:
{memoryForecast?.nearingLimit && (
  <Banner>
    Conversation is {Math.round(memoryForecast.contextUsedFraction * 100)}%
    full — {memoryForecast.remainingTokens} tokens left. Consider resetting.
  </Banner>
)}

// OS memory pressure (reset on each successful load):
{memoryWarning === "critical" && (
  <Banner>Device memory is critically low.</Banner>
)}
