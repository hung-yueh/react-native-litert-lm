Models & registry

The bundled model URL constants, the Models identifier map, and ModelRegistry — the single source of truth for model download and cache state.

Supported models

Only .litertlm bundles run. This is a native inference engine, not a Python runtime — raw HuggingFace checkpoints will not load. The library ships three ready-to-use URL constants; pass any of them straight to useModel() or loadModel().

ConstantSizeMin RAMModalities
GEMMA_4_E2B_IT 2.58 GB 4 GB+ Text, image, audio, tools, thinking
GEMMA_4_E4B_IT 3.65 GB 6 GB+ Text, image, audio, tools, thinking
GEMMA_3N_E2B_IT_INT4 deprecated ~3.66 GB 6 GB+ Text, image
typescript
export const GEMMA_4_E2B_IT =
  "https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm/resolve/main/gemma-4-E2B-it.litertlm";

export const GEMMA_4_E4B_IT =
  "https://huggingface.co/litert-community/gemma-4-E4B-it-litert-lm/resolve/main/gemma-4-E4B-it.litertlm";

export const GEMMA_3N_E2B_IT_INT4 =
  "https://models.litert.dev/gemma-3n-E2B-it-int4.litertlm";

All three URLs are public — no HuggingFace account or authentication required.

Prefer Gemma 4

GEMMA_3N_E2B_IT_INT4 is deprecated. GEMMA_4_E2B_IT is smaller (2.58 GB), adds audio, tool calling and thinking, and is served straight from the Hub. Gemma 3n is mirrored on models.litert.dev only because the upstream repo google/gemma-3n-E2B-it-litert-lm is gated — it returns 401 without an access token and manual license approval. The constant still works, and the former litert.dev/… URL redirects to the mirror, so shipped apps are unaffected.

iOS entitlement

All three bundled models exceed ~2 GB, so on iOS they need the Extended Virtual Addressing entitlement — without it, iOS caps virtual memory and kills the app during load.

Gemma 4 capabilities

Gemma 4

Gemma 4 models support thinking mode (reasoning content arrives in <thinking>…</thinking> markers), tool calling (<tool_call>…</tool_call> markers), audio input, and are NPU-optimized. The library parses the channel markers into typed events — see Inference & streaming.

Model identifiers

Models maps friendly names to the canonical model identifiers. Use it with model download utilities or as reference.

typescript
export const Models = {
  /** Gemma 4 E2B Instruct (2B parameters, latest generation) */
  GEMMA_4_E2B: "gemma-4-E2B-it-litert-lm",
  /** Gemma 4 E4B Instruct (4B parameters, higher quality) */
  GEMMA_4_E4B: "gemma-4-E4B-it-litert-lm",
  /** Gemma 3n E2B (2B parameters, efficient) */
  GEMMA_3N_E2B: "gemma-3n-E2B-it-litert-lm-preview",
  /** Gemma 3n E4B (4B parameters, higher quality) */
  GEMMA_3N_E4B: "gemma-3n-E4B-it-litert-lm-preview",
  /** Gemma 3 1B (smallest Gemma) */
  GEMMA_3_1B: "Gemma3-1B-IT_multi-prefill-seq_q4_ekv4096",
  /** Phi-4 Mini Instruct */
  PHI_4_MINI: "Phi-4-mini-instruct_multi-prefill-seq_q8_ekv4096",
  /** Qwen 2.5 1.5B Instruct */
  QWEN_2_5_1_5B: "Qwen2.5-1.5B-Instruct_multi-prefill-seq_q8_ekv4096",
} as const;

export type ModelId = (typeof Models)[keyof typeof Models];

Models without a bundled URL constant — Gemma 3 1B, Phi-4 Mini, and Qwen 2.5 1.5B — download manually from HuggingFace (litert-community), then load by local path or by your own HTTPS URL.

ModelRegistry

ModelRegistry is the single source of truth for model storage: it coordinates URL sniffing, HTTPS enforcement, atomic downloads with progress, and cache queries. createLLM's loadModel and the useModel hook both route through it — use it directly for pre-download UIs, cache management, and storage-usage screens.

isCached

isCached(pathOrUrl: string): boolean

Check if a model file is cached locally. Accepts a filename, local path, or HTTPS URL. Returns true if cached and the file has size > 0.

getFilePath

getFilePath(pathOrUrl: string): string

Get the absolute local path of a cached model. Accepts a filename, local path, or HTTPS URL.

listCachedFiles

listCachedFiles(): ModelFile[]

List all locally cached model files. Returns an array of ModelFile descriptors containing path, size, and modification time.

deleteFile

deleteFile(pathOrUrl: string): void

Delete a cached model file. Accepts a filename, local path, or HTTPS URL.

getFileSizeBytes

getFileSizeBytes(absolutePath: string): number

Size in bytes of a file at an absolute path (not restricted to the cache). Returns -1 if the file does not exist.

resolveModel

async resolveModel(pathOrUrl: string, options?: ModelDownloadOptions): Promise<string>

Resolve a model path or URL. Sniffs the protocol: an HTTPS URL is downloaded to the native cache directory (with throttled progress callbacks) if not already cached; a local path is returned directly. Resolves to the absolute local path of the model.

typescript
export interface ModelDownloadOptions {
  headers?: Record<string, string>;
  onProgress?: (progress: number) => void;
}

URL handling

  • A leading file:// prefix is stripped.
  • The cache filename is derived from the URL's last path segment, with the query string stripped.
  • When no filename can be derived, resolution throws Invalid model URL: <url>.
HTTPS only

http:// URLs are rejected with: Insecure HTTP URLs are not allowed for model downloads. Use HTTPS instead: <https-url>

ModelFile

typescript
export interface ModelFile {
  fileName: string;
  absolutePath: string;
  sizeBytes: number;
  lastModifiedMs: number;
}
Note

ModelFile is the return type of listCachedFiles(). It is currently not re-exported from the package root, so infer it from the return value rather than importing it by name.

Example: manage the cache

typescript
import { ModelRegistry, GEMMA_4_E2B_IT } from "react-native-litert-lm";

// 1. Check the cache before showing a download prompt
if (!ModelRegistry.isCached(GEMMA_4_E2B_IT)) {
  // 2. Download with progress (no-op if already cached)
  await ModelRegistry.resolveModel(GEMMA_4_E2B_IT, {
    onProgress: (p) => setProgress(Math.round(p * 100)),
  });
}

// 3. Absolute local path — pass to loadModel(), show in a storage UI, …
const path = ModelRegistry.getFilePath(GEMMA_4_E2B_IT);
console.log(path, ModelRegistry.getFileSizeBytes(path));

// 4. Free the multi-GB file when the user removes the model
ModelRegistry.deleteFile(GEMMA_4_E2B_IT);

Deprecated instance methods deprecated

The instance-level downloadModel(url, fileName, onProgress?) and deleteModel(fileName) methods are deprecated — ModelRegistry supersedes both. They remain callable, but new code should use ModelRegistry.resolveModel and ModelRegistry.deleteFile instead.
