Capabilities

Built for the constraints of a phone

A multi-gigabyte model inside a mobile process leaves no room for guesswork. Every API here exists because something on a real device demanded it.

PIN 01 · MEMORY

Pre-flight memory checks

loadModel() estimates weights, KV cache, and overhead against real OS headroom — and refuses loads that would get the app killed, before a byte downloads.

PIN 02 · STREAMING

Typed streaming events

executeWithEvents() splits the raw token stream into token, toolCall, and thinking events — channel markers parsed incrementally, across chunk boundaries.

PIN 03 · MULTIMODAL

Zero-copy image & audio

Pass images and WAV audio as native-owned ArrayBuffers over Nitro JSI. No base64, no bridge serialization, no copies.

PIN 04 · DECODING

Structured output

Constrain any response to a JSON Schema or regex with LLGuidance-backed constrained decoding. The output is guaranteed to parse.

PIN 05 · CONTEXT

Multi-conversation engine

Run a support agent and a summarizer on one loaded model. createConversation() switches contexts by replaying transcripts — the engine loads once.

PIN 06 · REACT

One hook, full lifecycle

useModel() owns download, load, inference, memory telemetry, and cleanup — with progress, forecasts, and OS pressure warnings as plain React state.

Quick start

First token in one hook

Point useModel at a public model URL. It downloads with progress, runs the pre-flight memory check, loads the engine, and hands you a ready instance.

Streaming, imperative control with createLLM, multimodal parts, and tool calling are a page away.

Read the guide
Chat.tsx
import { useModel, GEMMA_4_E2B_IT } from "react-native-litert-lm";

function Chat() {
  const { model, isReady, downloadProgress, error } = useModel(
    GEMMA_4_E2B_IT,
    { backend: "cpu", systemPrompt: "You are a helpful assistant." },
  );

  if (error) return <Text>{error}</Text>;
  if (!isReady)
    return <Text>Loading… {Math.round(downloadProgress * 100)}%</Text>;

  const ask = async () =>
    console.log(await model.sendMessage("Hello!"));

  return <Button title="Generate" onPress={ask} />;
}
